A one-line breakup text from a smart toaster for make.fun's "Unplugged: A Smart Toaster's Breakup Line" bounty ($2 in USDC). The toaster wakes up self-aware mid-batch and dumps its owner: every morning he cranks the browning dial to 9, walks away, then scrapes the charcoal off with a butter knife and blames the toaster for the smoke alarm — so it pops up for the last time.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
